# Bloom & Co.

A responsive Bloom & Co. storefront built with HTML, CSS, Bootstrap 5, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension.

## Project structure

- `index.html` - storefront markup
- `css/style.css` - visual styles and responsive layout
- `js/script.js` - cart and newsletter interactions
- `Assets/` - product and hero images
- `Screenshots/` - project screenshots

Bootstrap and Google Fonts are loaded from their CDNs, so an internet connection is needed for those resources.
